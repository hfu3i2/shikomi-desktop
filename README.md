# 仕込み管理システム

予約人数・コース構成をもとに、仕込み表の作成と必要食材量・発注候補の計算を行う個人制作のWindowsアプリです。

このリポジトリは就職活動向けのデモ版です。実際の予約・ログイン情報・保存済み業務データは含めていません。初期の卓設定は架空の設定へ変更し、自動取得は初期状態でOFFにしています。

## 主な機能

- 予約入力、コースと料理の設定、卓ごとの盛り分け
- 人数・料理設定に応じた仕込み量の計算
- 食材・在庫・包装単位に基づく発注候補の計算
- 仕込み表の印刷、バックアップと復元
- 外部予約サービスからの取得を行う補助処理（デモに認証情報は付属しません）

## 技術と構成

React / TypeScript / Vite、Tauri 2 / Rust、Windows SQLite、取得補助処理のNode.js / Playwright。

- `src/`：画面、計算処理、テスト
- `src-tauri/`：Windowsアプリ、保存・復元処理
- `worker/`：予約取得の補助処理
- `examples/`：架空のサンプルデータ

## ブラウザで画面を確認

Node.js 24で、リポジトリのルートから実行します。

```sh
npm ci
npm run dev
```

http://localhost:5173 を開きます。ブラウザ版ではローカル保存を使用し、Windows専用の印刷・ファイル復元・外部サービス接続機能などは制限されます。デモには実際の業務データを入力しないでください。

## Windowsアプリとして起動

RustとTauriのWindows開発環境、および同梱ランタイム準備用のNode.js v24.15.0が必要です。

```sh
npm ci
npm install --prefix worker
npm run prepare:distribution
npm run tauri dev
```

公開版はアプリIDを `dev.portfolio.shikomi.demo` に変更し、元のアプリの保存領域から分離しています。`examples/demo.json` は架空の予約・食材を含む復元用データです。デモアプリのバックアップ画面から復元し、2026年10月28日を選択してください。


## 実装で扱った点

盛り分けの手動変更、人数条件の境界、コースの料理構成の違い、食材の包装単位による切り上げを計算処理に分けています。バックアップの形式検証や、保存時の更新競合の検出も実装しています。

外部サービス接続・インストーラー・印刷の別PC検証は、今回の公開準備の検証には含めていません。実サービスの接続なしで画面と計算処理を確認できます。
